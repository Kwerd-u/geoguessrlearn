# GeoGuessrLearn

Тренажёр для изучения регионов России. Приложение показывает карту региона или его название и предлагает выбрать правильный ответ из четырёх вариантов.

## Режимы игры

- **Карта → Название** — угадай регион по его очертаниям на карте
- **Карта → Телефонный домен** — угадай телефонный код региона по карте
- **Название → Карта** — найди регион на карте по названию
- и другие комбинации

## Реализованные регионы

На данный момент в базе 5 регионов:
- Республика Башкортостан
- Республика Адыгея
- Ростовская область
- Москва
- Санкт-Петербург

## Стек

- Java 25
- Maven

## Запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Kwerd-u/geoguessrlearn.git
   ```
2. Открыть проект в IDE (IntelliJ IDEA)
3. Собрать и запустить через Maven:
   ```bash
   ./mvnw spring-boot:run
   ```
